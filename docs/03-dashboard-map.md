# PROMPT — DASHBOARD MAP
## GAME SEKOLAH MINGGU GKJ TANGERANG

Buat halaman awal game dalam bentuk **Adventure Map Alkitab** untuk anak Sekolah Minggu tingkat SD.

Dashboard bukan berupa menu biasa.

Dashboard harus terasa seperti **peta perjalanan Alkitab** yang mengajak anak memilih kelas dan memulai petualangan.

## STRUKTUR KELAS

### KELAS KECIL
SD Kelas 1–2

Karakteristik:
- visual besar dan sederhana;
- sedikit teks;
- banyak ikon dan gambar;
- instruksi sangat pendek;
- tantangan sederhana;
- fokus mengenal tokoh dan cerita.

### KELAS MADYA
SD Kelas 3–4

Karakteristik:
- mulai menggunakan puzzle;
- urutan cerita;
- kuis sederhana;
- hafalan ayat;
- hubungan sebab dan akibat;
- kerja sama kelompok.

### KELAS BESAR
SD Kelas 5–6

Karakteristik:
- tantangan lebih kompleks;
- puzzle;
- analisis cerita;
- timeline Alkitab;
- pilihan situasi;
- penerapan nilai karakter;
- kerja sama strategis.

# DASHBOARD UTAMA

## HEADER

**Bible Adventure**

### Perjalanan Besar Alkitab

Subjudul:

**Jelajahi cerita Alkitab dari Perjanjian Lama sampai Perjanjian Baru.**

# PILIH KELAS

Tampilkan tiga pilihan:

- **Kelas Kecil, SD 1–2**
- **Kelas Madya, SD 3–4**
- **Kelas Besar, SD 5–6**

Masing-masing memiliki tombol:

**Mulai Petualangan**

# ADVENTURE MAP

Tampilkan **Bible Journey Map** dengan checkpoint.

Urutan sederhana:

**Penciptaan → Nuh → Abraham → Yusuf → Musa → Yosua → Hakim-hakim → Raja-raja → Nabi-nabi → Pembuangan → Kelahiran Yesus → Pelayanan Yesus → Salib & Kebangkitan → Gereja Mula-mula**

Setiap bagian menjadi checkpoint.

# STATUS CHECKPOINT

Gunakan:

🔒 **Belum Terbuka**

▶ **Bisa Dimainkan**

⭐ **Sudah Selesai**

# INTERAKSI CHECKPOINT

Ketika checkpoint ditekan, tampilkan:

## Nama Cerita
Contoh: **Musa dan Keluaran dari Mesir**

## Posisi Timeline
Contoh: **Yusuf → Musa → Yosua**

## Misi
Contoh: **Bantu bangsa Israel keluar dari Mesir dengan menyelesaikan 3 tantangan.**

## Yang Akan Dipelajari
- cerita Alkitab;
- ayat;
- nilai karakter;
- urutan sejarah Alkitab.

Tombol:

**MULAI MISI**

# CORE FLOW DASHBOARD

**PILIH KELAS → LIHAT MAP → PILIH CHECKPOINT → LIHAT MISI → MULAI GAME → SELESAIKAN TANTANGAN → KEMBALI KE MAP → CHECKPOINT BERIKUTNYA TERBUKA**

# PROGRESS

Gunakan progres sederhana.

Contoh:

**2 dari 10 perjalanan selesai**

Jangan gunakan XP, currency, inventory, shop, atau fitur kompleks pada prototype pertama.

# PERBEDAAN ANTAR KELAS

Cerita dan map boleh sama.

Yang berubah adalah tingkat kesulitan.

Contoh Daud dan Goliat:

### Kelas Kecil
Pilih gambar yang benar.

### Kelas Madya
Susun urutan cerita.

### Kelas Besar
Analisis alasan dan nilai dari tindakan tokoh.

Gunakan prinsip:

**Satu cerita → Tiga tingkat interaksi**

# NAVIGASI UTAMA

- 🏠 Beranda
- 🗺️ Bible Map
- 🎮 Misi
- ⭐ Progress

Maksimal 4 menu utama.

# MOBILE FIRST

Prioritaskan smartphone.

Gunakan tombol besar dan area sentuh yang nyaman.

# PROTOTYPE VERSION

Untuk prototype pertama, buat:

- 1 dashboard;
- 3 pilihan kelas;
- 1 Bible Map;
- 5 checkpoint awal.

Checkpoint awal:
1. Penciptaan
2. Nuh
3. Abraham
4. Yusuf
5. Musa

Tujuan pengujian:
1. Apakah anak memahami cara memilih kelas?
2. Apakah anak memahami konsep map?
3. Apakah anak tahu checkpoint mana yang harus dimainkan?
4. Apakah anak tertarik melanjutkan perjalanan?
5. Apakah anak mulai memahami urutan cerita Alkitab?

# PERINTAH UTAMA

Buat dashboard prototype game Sekolah Minggu GKJ Tangerang dalam bentuk **interactive Bible Adventure Map**.

Gunakan:
