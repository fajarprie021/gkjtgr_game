# v2 Backlog

> Daftar ide dan fitur yang **sengaja tidak** dimasukkan ke v1
> dan dipertimbangkan untuk rilis selanjutnya.
>
> Jangan kerjakan item backlog ini sampai v1 stabil dan release decision
> final disetujui.

---

## Prinsip Backlog

- Backlog bukan daftar janji.
- Item hanya naik prioritas kalau ada evidence kebutuhan nyata.
- Hindari vote-driven features (lihat `prompt/13` section #94).
- Setiap item harus mendukung:
  - learning
  - usability
  - classroom operation
  - teacher/admin workflow

---

## Cara Naikkan Prioritas

```text
1. Kumpulkan evidence kebutuhan dari observasi nyata
2. Pastikan evidence mendukung learning atau classroom operation
3. Evaluasi risiko teknis dan dampak ke deployment
4. Bawa ke iterasi selanjutnya dengan status baru
```
